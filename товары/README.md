# Товары Coulair Club

Каждый товар — отдельная папка здесь. В папке:

- **`товар.txt`** — название, цена, размер, описание (образец — [`_шаблон/товар.txt`](_шаблон/товар.txt));
- **фото** в `.jpg`, `.png` или `.webp`. Порядок — по имени файла, первое фото главное.
  Удобнее всего называть `1.jpg`, `2.jpg`, `3.jpg`…

Имя папки становится адресом страницы: папка `tsg-zebra` → `coulair.ru/catalog/tsg-zebra/`.
Лучше называть латиницей через дефис. Кириллицу тоже можно, её переведёт в латиницу автоматически.

После любого изменения на GitHub сайт **пересобирается сам** за 1–2 минуты
(ход сборки — во вкладке **Actions** репозитория). Если в карточке ошибка, сборка
остановится, и в Actions будет написано, в каком файле и что не так. Старая версия сайта при этом продолжит работать.

## Добавить товар (через сайт GitHub)

1. Откройте папку `товары` → **Add file → Create new file**.
2. В поле имени напишите `название-папки/товар.txt`: косая черта сама создаст папку.
3. Вставьте содержимое [`_шаблон/товар.txt`](_шаблон/товар.txt), заполните и нажмите **Commit changes**.
4. Зайдите в новую папку → **Add file → Upload files**, перетащите фото и нажмите **Commit changes**.

Фото с Авито можно загружать как есть: поставьте в карточке `авито: да`, и водяной знак срежется сам.

## Самый быстрый способ: папка с Авито

Можно не заполнять `товар.txt`: создайте папку, загрузите в неё фото с Авито как есть
и файл **`описание.txt`**, в который вставлен текст объявления. В конце добавьте строку с ценой:

```
цена: 5000
```

Сборщик сам возьмёт из текста название, бренд, размер и состояние, срежет водяной знак Авито
с фото и уберёт из описания блоки «Почему стоит заказать у нас» и «Отправим Авито Доставкой».
Если что-то распознается не так, скопируйте в папку `_шаблон/товар.txt` и заполните вручную:
`товар.txt` всегда важнее `описание.txt`.

## Изменить цену или описание

Откройте `товар.txt` нужного товара, нажмите карандаш (**Edit**), поправьте и нажмите **Commit changes**.

## Продано / скрыть / удалить

- **Продано:** `в наличии: 0`. Товар останется на сайте серым с пометкой «Продано».
- **Скрыть:** `скрыть: да`. Товара не будет на сайте, папка останется.
- **Удалить совсем:** удалите все файлы из папки (у каждого файла **⋯ → Delete file**).
  Пустая папка на GitHub исчезает сама.

## Через git на компьютере

```bash
git pull                            # забрать последние изменения
# …правите файлы в папке товары/…
python3 tools/build_catalog.py      # по желанию: собрать и открыть index.html у себя
git add товары && git commit -m "Новый товар" && git push
```

Папку `catalog/` руками не трогайте, она каждый раз собирается заново из `товары/`.
Для обрезки водяного знака при локальной сборке нужен Pillow: `pip install Pillow`
(на GitHub он уже есть).
